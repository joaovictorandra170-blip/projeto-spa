🎬 CineFlix

CineFlix é um projeto de site desenvolvido para apresentar e organizar informações sobre filmes, com uma interface inspirada nas plataformas de streaming.

O projeto foi desenvolvido como atividade acadêmica, utilizando HTML, CSS e JavaScript, aplicando conceitos de desenvolvimento de uma Single Page Application (SPA).

🎯 Objetivo

Desenvolver uma aplicação web interativa que permita visualizar filmes, consultar informações e navegar entre diferentes áreas do site sem recarregar a página.

🛠️ Tecnologias utilizadas

- HTML5: estrutura da aplicação.
- CSS3: estilização e layout da interface.
- JavaScript: funcionalidades, navegação e manipulação do DOM.

🎥 Funcionalidades

- Página inicial com apresentação dos filmes.
- Navegação entre diferentes seções sem recarregar a página.
- Exibição de filmes disponíveis no catálogo.
- Visualização de informações e sinopses dos filmes.
- Cadastro de filmes.
- Listagem dinâmica dos filmes cadastrados.
- Organização do conteúdo em uma interface inspirada na Netflix.
